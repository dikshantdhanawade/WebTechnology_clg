# Experiment E10: React Student Dashboard Application

## Objective
To understand and implement concepts related to developing a React-based student dashboard application.

## Prerequisites
- Basic knowledge of Web Technologies
- Node.js / Browser installed

## Theory
This experiment helps students understand how to develop a React-based student dashboard application through hands-on implementation. The dashboard presents student performance data, attendance, and course summary in a clean interface.

## Procedure
1. Create required project structure
2. Implement dashboard UI using React
3. Add student data and summary statistics
4. Style dashboard components with CSS
5. Execute and verify output

## Features Implemented
- **Dashboard Summary Cards**: Total students, average age, average attendance, distinct courses
- **Student Performance Table**: Displays student ID, name, age, course, grade, and attendance
- **Responsive Dashboard Layout**: Adapts to desktop and mobile browsers
- **Modern UI Styling**: Clean cards, table formatting, and hover states

## Technologies Used
- **React 19**
- **Webpack**
- **Babel**
- **CSS**

## Project Structure
```
react-student-app/
├── public/
│   └── index.html
├── src/
│   ├── index.js
│   ├── App.js
│   └── App.css
├── package.json
├── package-lock.json
└── webpack.config.cjs
```

## How to Run
1. Open terminal in `react-student-app`
2. Install dependencies: `npm install`
3. Start development server: `npm start`
4. Open browser at `http://localhost:3000`

## Result
The experiment was executed successfully and the desired output was obtained. The React dashboard shows student metrics and performance data clearly.

## Conclusion
This experiment helped in understanding how to develop a React-based student dashboard application in a practical manner. Key concepts learned include:
- React component development
- State and data display
- Dashboard layout design
- CSS styling and responsive UI
- Webpack configuration
